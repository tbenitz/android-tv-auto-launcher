Safety alert: v1.1.x TV Home freeze reported

Older builds should not be installed as Home. Orbit TV v2 is a test-only preview. A Mi Box user reported that version 1.1.1 freezes when used as Home. Do not use v1.1.1 as Home. Install the v2 preview only as a normal app first, and keep your stock Home enabled while testing all navigation and recovery paths.

Recovery: If you previously disabled the original Mi Box launcher, reconnect using ADB from an Android phone or computer. Run pm enable --user 0 com.google.android.tvlauncher in the ADB shell. If successful, run pm disable-user --user 0 io.github.tbenitz.tvautolaunch, then input keyevent 3. Confirm the package is present before disabling anything. This doesn't erase your apps or saved data. Do not factory reset as a first step.

Install in minutes

Download and sideload

Choose whichever installation method works for your TV. You don't need to root the device.

Option A — Directly on your TV

  1. Open this page in a TV browser or Downloader app, or download the APK on your phone and send it to your TV with a file-transfer app.
  2. Select Download APK above.
  3. Allow the browser / file manager to install unknown apps when Android asks.
  4. Install and open Orbit TV.

Tip: some TV browsers may download more easily from the Releases page than from a direct link.

Option B — From another device (ADB)

  1. Enable Developer options on your TV and enable the available network / wireless debugging option.
  2. Find your TV's IP address and connect using Android Debug Bridge.
  3. Install the downloaded APK.
adb connect TV_IP:5555
adb install -r TVAutoLaunch.apk

Wireless debugging on Android 11+ may require pairing and a different port.

Last step

Choose your startup app, then test before changing Home

  1. Open Orbit TV. Choose Settings → Startup app (or select an app in All apps and choose Make startup app).
  2. Test opening apps and returning with Back, then leave Auto-launch ON. Only after verifying the launcher on your box should you consider its default Home option.
  3. Restart your Android TV to test. The target app should open once the Home launcher starts.
Google TV compatibility note: Some certified devices block changing the default Home app. Automatic launch cannot be guaranteed unless the device actually uses Orbit TV as Home. If the picker doesn't work, see the optional ADB method below.

Optional: set Home through ADB

Try the following command only if your TV allows ADB and the built-in Home picker fails. It makes no system-package changes.

adb shell cmd package set-home-activity io.github.tbenitz.tvautolaunch.preview/io.github.tbenitz.tvautolaunch.MainActivity
adb shell cmd package resolve-activity -a android.intent.action.MAIN -c android.intent.category.HOME

If the original TV launcher remains active, firmware may override Home. Avoid blindly disabling Google/system packages; the wrong command could leave the TV without a usable Home screen. Restoration guide and technical details.

Mi Box troubleshooting

Mi Box won't let you set Home?

The Orbit TV APK is already registered as a Home launcher. Some Xiaomi Android TV firmware does not display the Home app picker. No root or system file modifications are needed; use Android debugging to select it.

1. Enable debugging on the Mi Box

  1. Make sure Orbit TV is installed, open it from Apps, and choose the streaming app you want to start.
  2. Open Settings → Device Preferences → About → Build and press OK seven times.
  3. Open Developer options and enable the available USB, network, or Wireless debugging method.
  4. Find the TV IP under Network settings. From an ADB client on a computer or Android phone on the same network, connect:
adb connect TV_IP:5555

Replace TV_IP with the Mi Box's address. Wireless debugging on newer versions may require a pairing code and a different port. An Android phone ADB client or TV Box Tools can be used instead of a computer.

2. Set our app as the Home launcher

adb shell cmd package set-home-activity io.github.tbenitz.tvautolaunch/.MainActivity

3. Check the selected Home activity

adb shell cmd package resolve-activity -a android.intent.action.MAIN -c android.intent.category.HOME

Press HOME and restart the Mi Box to test. Some Mi Box firmware may still force its original launcher despite successful ADB output.

Advanced fallback: if the original Home still opens

Use caution: Only if you confirm the Mi Box's actual competing launcher is com.google.android.tvlauncher, Orbit TV works from Apps, and you have working ADB access for recovery, you may disable that specific stock Home package. Do not disable unknown packages, uninstall system launchers, or disable setup services.

Disable only the confirmed Android TV launcher for the current user:

adb shell pm disable-user --user 0 com.google.android.tvlauncher

Undo: restore original Home

adb shell pm enable --user 0 com.google.android.tvlauncher

If your box uses another stock launcher package, these commands do not apply. Read the Mi Box setup and recovery instructions.

Good to know

Frequently asked questions

Will it work on my Android TV box or Mi Box?

It uses Android 6.0+ standard SDK APIs and has no processor-specific native libraries. Whether automatic startup works depends on your box allowing third-party apps to be set as the default Home launcher. Firmware behavior varies; verify with a reboot.

Does it automatically reopen the selected app every time I press Home?

No. The target app is launched once per system boot. Later presses of Home return to the Orbit TV settings screen, avoiding a relaunch loop.

Can I switch back to the original Android TV launcher?

Yes. Change the default Home app in system settings before uninstalling Orbit TV. If your firmware required ADB, follow the restoration instructions in the source repository. This app never disables the stock launcher on its own. The v2 preview installs under a separate .preview package.

Why doesn't my installed app show up?

Only apps that expose an ordinary or TV launcher activity appear. Check that the target app is fully installed and has an app icon, then choose Refresh installed apps.

Is it safe to install?

The app source is public. It uses Internet permission only for explicitly requested APK downloads, and Android's normal user-confirmed installer. It does not request Accessibility or root access. APK files are provided through the linked public GitHub Releases. Download only from the official repository URL; inspect the workflow, source, and SHA-256 checksum if you want to verify the build.
